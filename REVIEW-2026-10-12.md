# ThyncSpace frontend review — 12 October 2026

Integrated the reviewed calculator, document editor and Noteboard packages. The host
uses the package editor and its collaboration history, with full-width editing,
scoped slash shortcuts and responsive toolbars.

The follow-up fixes stale private saves, misleading save labels, per-tab draft
collisions, lost live drafts after page closure, reconnect unmounts, profile-driven
provider restarts, collapsed same-account presence, pan-only modification times,
missing import paths and whole-board storage limits. Private save conflicts have
a comparison and downloadable copies. Drafts are account/session scoped; existing
private drafts migrate after the API confirms ownership. Failed storage writes
remain in memory during navigation and are never described as durably stored.

Live receipts acknowledge canonical content/title/board state after MongoDB writes.
The first real WebSocket test found binary hashes differed because undo retention
and garbage collection differ between replicas; semantic hashes fixed that issue.
Pending CRDT edits persist locally and replay through normal server authorization.
A retired provider can close after local persistence succeeds. If persistence
fails, pending changes remain in memory and exit warnings/downloads stay available.

Organization supports notebook/tag editing and filtering. Recovery includes the
last five versions, version names and side-by-side content comparison, private
restore copies, trash restore and confirmed permanent deletion. The calculator
is private and has no note-insertion or shared recalculation controls.
