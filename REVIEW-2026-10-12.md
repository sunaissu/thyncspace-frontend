# ThyncSpace frontend review — 12 October 2026

Integrated the reviewed calculator, document editor and Noteboard packages. The host
uses the package editor and its collaboration history, with full-width editing,
scoped slash shortcuts and responsive toolbars.

The follow-up fixes stale private saves, misleading save labels, per-tab draft
collisions, lost live drafts after page closure, reconnect unmounts, profile-driven
provider restarts, collapsed same-account presence, pan-only modification times,
missing import paths and whole-board storage limits. Private save conflicts have
a comparison and downloadable copies. Drafts are account/session scoped; existing
private drafts migrate after the API confirms ownership. Failed storage writes
remain in memory during navigation and are never described as durably stored.

Live receipts acknowledge canonical content/title/board state after MongoDB writes.
The first real WebSocket test found binary hashes differed because undo retention
and garbage collection differ between replicas; semantic hashes fixed that issue.
Pending CRDT edits persist locally and replay through normal server authorization.
A retired provider can close after local persistence succeeds. If persistence
fails, pending changes remain in memory and exit warnings/downloads stay available.

Organization supports notebook/tag editing and filtering. Recovery includes the
last five versions, version names and side-by-side content comparison, private
restore copies, trash restore and confirmed permanent deletion. Saved calculation
blocks preserve inputs and operation settings and use the safe calculator engine.

## Verification

- Typecheck and ESLint pass with no warnings; calculation and draft storage tests pass.
- Production static export passes after migrating to Tailwind 4.3.3.
- Full and production dependency audits report zero vulnerabilities. Tailwind 3
  and the Next ESLint bundle were removed. Direct TypeScript, React, hooks, import
  and accessibility rules remain; Next-specific plugin rules are no longer loaded.
- Chrome fixture suite covers typing, organization, version names/comparison,
  recovery, permanent-delete confirmation, saved calculations and board mounting.
  Layout checks include 320, 390, 768 and 1440px; narrow library controls also pass.
- Two-tab Chrome suite covers stale rejection, comparison/download/restore, failed
  save labels and retained drafts.
- Chrome with a real local WebSocket server and disposable MongoDB replica set
  verifies durable receipts and pending live edits surviving page closure/reopening.
  OAuth/session lookup uses fixtures; production accounts are never contacted.

## Remaining product scope

The broad candidate backlogs are not all shipped. Cross-note embeds, unit-aware
live formulas, full offline library browsing, attachment storage, billing and the
other candidate product features remain separate implementation work. Five saved
versions are recovery snapshots, not an immutable audit log. Cloud configuration,
production OAuth, backup restoration, multi-instance deployment and load capacity
were not certified by these local checks. Nothing was published or deployed.

Follow-up: named per-session pointer cursors now work for both editors; calculator insertion was removed per the updated privacy requirement. The two-account test found and fixed a disconnect render crash. Board viewport reads no longer clone the board. Restored private drafts are cleared only after confirmed saves, and obsolete copies matching server content are cleaned up. The cursor test also covers same-account tabs and checks that calculator inputs are absent from both Yjs and awareness.
